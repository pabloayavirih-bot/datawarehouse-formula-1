# Data Warehouse - Formula 1 (1950-2024)

Proyecto Final de Sistemas Gerenciales.

## Objetivo

Implementar un Data Warehouse para analizar los datos historicos
del Campeonato Mundial de Formula 1 entre 1950 y 2024.

## Arquitectura

- Terraform
- Microsoft Azure
- Azure Storage Account (Raw)
- Azure SQL Database (Bronze, Silver y Gold)
- Azure Data Factory
- Tableau

## Modalidad

Individual: 6 dimensiones y 2 tablas de hechos.

## Universidad

Universidad Catolica Boliviana San Pablo.
